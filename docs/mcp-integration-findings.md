# Descobertas da integração do MCP

O repositório `felipetjmg1-bit/oraculo-x37` já possui uma base Python com FastAPI, scikit-learn, SHAP, pandas, NumPy, Matplotlib, testes Pytest e configuração de contêiner. O README existente descreve os pilares de soberania tecnológica, soberania de dados e segurança/resiliência.

A implementação inicial do MCP foi criada separadamente em `/home/ubuntu/oraculo-x37-mcp/server.py` e usa FastMCP, com ferramentas determinísticas para simulação de futuros, explicabilidade, auditoria algorítmica, monitoramento de ativos e avaliação de decisões. A integração deve preservar os arquivos existentes e adicionar um submódulo ou diretório claramente identificado, além de declarar `fastmcp` como dependência compatível.
